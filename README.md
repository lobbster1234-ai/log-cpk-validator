# Log CPK Validator

產線測試 log 的格式檢查工具。把 log 丟進網頁，就知道它能不能順利產出 CPK 報表。

## 這是什麼

CPK 報表產生工具對 log 的格式要求很嚴格。測試程式換版、或 log 被編輯過，都可能讓報表產不出來，而錯誤訊息通常看不出問題到底在哪一行。

這個網頁把那些格式要求整理成 15 條檢查規則，直接告訴你問題在第幾行、原因是什麼、該怎麼處理。

## 功能

- 合格顯示 **OK**，不合格顯示 **NG**，並指出問題在第幾行、什麼原因、怎麼處理
- 分三級：不合格（產不出報表）／注意（產得出來但可能漏測項）／合格
- 可拖檔或貼上，也可一次拖多個
- 可一鍵匯出 Excel，不合格的列標粉色、注意的標黃色

## 使用方式

直接開啟網頁，把 `.log` 檔拖進去即可。

也可以下載 `index.html` 存在本機，用 Edge 或 Chrome 開 —— 不需要安裝、不需要連網，產線離線電腦也能用。

> 請用 Edge 或 Chrome，IE 不支援。

## 隱私

log **只在你的瀏覽器裡解析，不會上傳到任何伺服器**，也不會寫進任何紀錄。

整個工具是單一 HTML 檔，沒有引用任何外部資源（無 CDN、無字型、無分析套件），所以斷網也能正常運作。

## 開發

單一檔案，沒有建置流程，直接編輯 `index.html` 即可。

- 檢查規則定義在 `RULES` 物件，每條含四個欄位：
  `title`（問題名稱）／`problem`（是什麼狀況）／`impact`（為什麼會產不出報表）／`fix`（怎麼處理）
- 嚴重度 `sev` 有三種：`fatal`（不合格）／`warn`（注意）／`info`（參考）
- 匯出的 Excel 是用原生 JS 直接組出 xlsx（ZIP + XML），不依賴任何套件
- 改版時請一併更新頁面右上角的版本號

## 驗證方式

規則是從 CPK 產生工具的原始碼推導出來的，並用實際案例雙向驗證：

- 已知會失敗的 log → 必須判 NG，且指出的行號與工具實際中止的位置一致
- 已知正常的 log → 必須判 OK，不能誤報
- 另外把正常的 log 故意改壞 9 種方式（拿掉時間戳、破壞括號、刪掉通過標記等），逐項比對工具的實際行為，確認嚴重度判定一致
